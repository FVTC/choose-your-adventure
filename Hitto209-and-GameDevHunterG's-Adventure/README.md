# ✨ A Markdown-Based Adventure Framework


 Hello! This repo is Hitto209 and GameDevHunterG's take on the "choose your own 
 adventure" format, using Markdown files. We wanted to creat a simple yet fun 
 story that follows a D&D style adventure. In This adventure, we will be using a 8 
 sided die (d8) and a 20 sided die (d20) to determine the outcome of certain 
 choices.
