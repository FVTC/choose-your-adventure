# Ending 1: Run Away, Don't Ask Questions

You bolt out of the hallway and back into the main part of the library. The air feels normal again, the humming quiet. The strange glow? Gone.

You glance back — the hallway is no longer there. Just a solid wall of bookshelves. Had it ever been there at all?

You walk home that day, safe... but haunted by the mystery you'll never solve.
